# AI Learning Platform

**A web-based adaptive learning platform that helps students prepare for aptitude and placement tests with AI-powered personalized feedback and weak area detection.**

Live link - https://ai-learning-platform-9ul9.onrender.com 

---

## Problem Statement

Students preparing for competitive exams and placement tests face significant challenges:

- **Lack of Self-Awareness**: Difficulty identifying which topics are weak without manual tracking
- **Generic Learning**: Traditional practice platforms provide one-size-fits-all questions without personalization
- **No Actionable Insights**: Absence of detailed analytics and targeted recommendations
- **Time-Consuming Analysis**: Manual calculation of performance metrics across multiple attempts
- **Limited Feedback**: No AI-driven suggestions on what to focus on next

The **AI Learning Platform** solves these problems by providing intelligent analytics, adaptive questioning, and data-driven recommendations tailored to each student's performance.

## Features

| Feature | Description |
|---------|-------------|
| **User Authentication** | Secure registration and login with password validation and duplicate prevention |
| **Static Quiz** | 10 curated questions on aptitude topics with immediate feedback and shuffled order |
| **AI-Adaptive Quiz** | Dynamic questions generated by Groq AI API based on student's weak areas |
| **Analytics Dashboard** | Real-time statistics including accuracy, attempt count, average time per question, and trends |
| **Weak Area Detection** | Automatic identification of topics with low accuracy and inconsistent performance |
| **Personalized Recommendations** | AI-generated study suggestions prioritized by urgency and difficulty level |
| **Performance Tracking** | Historical data on quiz sessions with detailed per-topic analysis |
| **Responsive Design** | Works on desktop, tablet, and mobile devices |

## Installation

### Prerequisites

- Python 3.8 or higher
- pip (Python package manager)
- Virtual environment tool (venv)
- Groq API key (free from https://console.groq.com)

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/AI-Learning-Platform.git
cd AI-Learning-Platform
```

### Step 2: Create and Activate Virtual Environment

**On Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**On macOS/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### Step 3: Install Dependencies

```bash
cd backend
pip install -r requirements.txt
```

### Step 4: Set Up Environment Variables

Create a `.env` file in the `backend/` directory with the following content:

```env
# Django Configuration
DEBUG=True
SECRET_KEY=your-secret-key-here
ALLOWED_HOSTS=localhost,127.0.0.1

# Groq API Key (for AI question generation)
GROQ_API_KEY=your-groq-api-key-here

# Database (optional, uses SQLite by default)
DATABASE_URL=sqlite:///db.sqlite3

# Session Configuration
SESSION_COOKIE_SECURE=False
SESSION_COOKIE_HTTPONLY=True
```

### Step 5: Apply Database Migrations

```bash
python manage.py migrate
```

### Step 6: Create a Superuser (Optional - for Admin Access)

```bash
python manage.py createsuperuser
```

Follow the prompts to create an admin account. Access admin at `/admin/`

### Step 7: Run Development Server

```bash
python manage.py runserver
```

The application will be available at **`http://127.0.0.1:8000/`**

## How to Use

### 1. **Register a New Account**

- Navigate to the registration page (`/register/`)
- Enter a unique username and email address
- Create a strong password (Django validators will check strength)
- Click **Register** to create your account

### 2. **Log In**

- Use your credentials to log in at the login page
- Redirected to the dashboard (first-time users see empty stats)

### 3. **Take Your First Quiz**

- Click the **Practice** button on the dashboard
- First-time users automatically start with the **Static Quiz** (10 questions)
- Questions are shuffled randomly for each attempt
- Answer each question and see immediate feedback (correct/incorrect)
- Time taken per question is tracked automatically

### 4. **View Quiz Results**

After completing a quiz, the **Quiz Summary** shows:
- Number of correct answers
- Overall accuracy percentage
- Total time spent
- Average time per question
- Results are automatically saved to your profile

### 5. **Analyze Your Weak Areas**

Navigate to **Weak Areas** section to:
- View topic-wise performance breakdown
- See accuracy percentages for each topic
- Identify topics classified as Strong, Moderate, or Weak
- Weak topics are flagged with priority levels (High, Medium, Low)

### 6. **Get Personalized Recommendations**

Visit **Recommendations** page to receive:
- **Targeted Study Suggestions**: High-priority topics recommended first
- **Reason Analysis**: Why each topic needs attention (low accuracy, speed issues, inconsistency)
- **Actionable Steps**: Specific practice suggestions for each weak area

### 7. **Take an AI-Adaptive Quiz**

After completing your first quiz:
- The **Adaptive Quiz** option unlocks
- Questions are **generated dynamically** using Groq AI
- Personalized based on your weakest areas
- Adaptive difficulty based on your performance history

### 8. **Track Your Progress**

The **Dashboard** displays:
- Total questions attempted across all quizzes
- Overall accuracy percentage
- Average time spent per question
- Topic-wise accuracy breakdown
- Historical trends from last 5 quiz sessions
- Performance charts for visual analysis
